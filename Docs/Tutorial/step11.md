# Aiursoft Template Tutorial - Step 11 - Localize Your App for a Global Audience

Keep user-facing source strings in English and use the existing `Localizer` in Razor views, as demonstrated in [Step 3](./step3.md). For model validation messages, follow the localized DataAnnotations examples in the [Model Validation guide](../Features/Validation.md).

Use the project's existing DotLang localization workflow to extract and translate resource strings instead of maintaining separate translated views or hard-coding a language in your controllers. Check the resulting page and validation messages in the languages your users need.

Continue with [Step 12 - Deploy the Application](./step12.md).
